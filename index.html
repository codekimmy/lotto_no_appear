🎯 로또 출현번호 빈도 대시보드

직전 5~15회 실제 출현번호를 색상과 횟수로 표시 · Google Sheets 연동
[▶ 분석 실행] 버튼을 누르면 시트에서 데이터를 불러와 분석합니다.
출현 횟수: 1회 2회 3회 4회 5회 6회+ (배지 숫자 = 실제 출현 횟수)
※ 페이지는 [▶ 분석 실행] 버튼을 눌러야 시작됩니다 (자동 실행 안 함).
※ 기본값은 최근 100회차만 표시 → 빠릅니다. “표시 개수”를 늘리면 더 많이 보입니다.
※ 렌더링은 배치(20개씩)로 처리되어 페이지가 멈추지 않습니다.
※ 각 셀 = 해당 회차의 직전 N회차 동안 실제로 출현한 모든 번호 (중복 제거, 오름차순).
